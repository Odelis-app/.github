# Odelis

**A space for thought.**

Odelis is a personal workspace for learning, planning, and organizing ideas. It brings academic productivity and personal organization into a calm, focused environment designed to help you spend less time managing your work and more time doing it.

## Vision

Odelis aims to make school and personal productivity feel more intentional. Rather than overwhelming users with features, it prioritizes clarity, thoughtful organization, and tools that work together.

### Design principles

- **Clarity over clutter** — Keep the interface focused on what matters.
- **User control** — Help users plan and organize their work without taking control away from them.
- **Thoughtful design** — Combine a forest-green and warm-ivory palette with restrained typography and generous whitespace.
- **Incremental improvement** — Build a reliable foundation before adding unnecessary complexity.

## Planned workspace

Odelis is being developed around several core areas:

- **Overview** — A central place to see priorities and get oriented.
- **Planner** — Organize tasks, plan time, and structure work.
- **Notes & Library** — Keep notes, resources, and reference material organized.
- **Learning** — Support studying through structured learning tools and review.

These areas are part of the product direction and are being developed incrementally.

## Technology

The current application uses:

- HTML
- CSS
- JavaScript

The project will evolve as its needs grow, with an emphasis on maintainability, accessibility, responsiveness, and reliable functionality.

## Getting started

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Odelis-app/odelis.git
   ```

2. Open the project directory:

   ```bash
   cd odelis
   ```

3. Open `index.html` in your browser.

No build step is currently required for the basic application.
